# 操作・戦術・道具の実行用ガイド（v0.20.3）

公開資料の独自要約と利用者指定から作成。初代SFCの効果・敵特性はリマスターでの確認候補であり、現在の仕様・数値と断定しない。所持・現在選択・敵の種類は画面と実測で確認する。これらの手順をキーの固定列として連続再生しない。

## 現在のボタンと場面別の作用

|キー|作用と確認点|
|---|---|
|W/A/S/D|通常時は移動、メニュー・選択肢ではカーソル移動。白枠がある操作を地形移動として数えない。|
|Num1|通常時は攻撃/話す、メニューでは決定、利用者の外部マップではドアを開く候補。対象と場面を先に確認。|
|Num2|キャンセル/ダッシュ。通常選択肢の取消は「いいえ」相当や前画面への復帰になり得る。ダッシュの方向・押下条件は実機確認が必要。|
|Num5＋方向|その場の方向転換。Num5は整理も兼ねる。位置移動・撃破は期待しない。ゲーム内のターン消費まで未確認のまま決め付けない。|
|Num0|メニュー。道具・状態を見る準備であり、開閉だけで攻略が進むとは評価しない。|
|Num4|矢。向き・射線・残弾を先に確認する。無反応の理由は空撃ち/壁/方向/処理待ち等に分ける。|
|Num3|斜め移動補助。組合わせ・押下条件は案内と実測で確認し、補助キー単独を移動成功に数えない。|
|Num7を保持|マップとHUDの専用表示。ツールの補助観測で使い、離した後の通常画面を取り直す。移動や攻略成果に加算しない。|
|Num6|足踏み。位置を変えずターンを進める用途。敵や空腹がある場合の損失を考慮し、無入力待機と区別する。|
|Enter / Space|現在のキー配置では使用しない。上段数字キーとテンキーを区別する。|

メニューを開いたら現在の項目→道具→品→使用法のそれぞれでカーソルを確認し、方向又は決定を1回送る。反応・再入力可能な画面への復帰を観測してから次を選ぶ。ボタンの割当は利用者確認済みだが、全場面のターン消費・入力時間・角越しの攻撃可否等は未検証。

## 初代資料の数値を使う場合

初代資料では薬草はHP25、弟切草はHP100回復、ラリホー草の睡眠は5ターン、火炎草を飲む炎は前方1マスに65〜75、イオは5〜25ダメージとされる。これらは初代の参考値で、リマスターのバランス調整後の保証値ではない。LLMへの状況別注入は固定数値より用途と確認手順を優先し、実測で補正する。

## 状況別の具体的な手順

### turn-economy

適用条件：ダンジョンで移動・攻撃・道具使用を選ぶとき。

期待する作用：移動等に伴って敵も行動する。無入力の実時間待機はゲーム内のターン消費やHP回復を意味しない。

照合・失敗時：ツールの1手・アニメーション・向き変更・メニュー操作を同じターン消費と決め付けず、位置・HP・敵の動きを別々に照合する。

版・根拠：`remaster_general` / steam-remaster-20261025, sfc-wiki-20261025, user-controls

### adjacent-attack

適用条件：現在の地図で敵表示が隣接。敵の個体名・向きは未確認。

期待する作用：必要なら方向転換してから決定/攻撃を1回。新しい命中表示があり同じ隣接表示が残るなら再攻撃を候補にする。

照合・失敗時：向き変更だけで撃破を期待しない。HP変化・命中/撃破の新しい文章・敵位置を照合。無反応だけで命中・空振りを断定しない。

版・根拠：`editorial_application` / steam-remaster-20261025, user-controls

### contact-position

適用条件：敵が遠い、または複数隣接している。

期待する作用：遠い敵への攻撃反復より、射程と移動後の接触数を比較。複数敵なら一度に受ける攻撃を減らす位置を候補にする。

照合・失敗時：移動しても敵が追う可能性があり、距離だけで安全とはしない。倍速・遠隔攻撃等の特性は現在の文章と経験から確認する。

版・根拠：`editorial_application` / sfc-wiki-20261025, steam-remaster-20261025

### explore-not-ui

適用条件：階と実マップを観測し、未探索の通路や現在目的への経路がある。

期待する作用：現在の通行実績と地図から1マスずつ進み、未知領域・目的地への接近を確認。

照合・失敗時：方向転換だけ、メニュー開閉、空の攻撃で新しい床への到達は期待しない。必要な状態確認以外のUI反復を探索成果と混同しない。

版・根拠：`editorial_application` / steam-remaster-20261025, user-controls

### recovery

適用条件：現在HPが低い。満腹度、敵の隣接や射線、回復品の所持を確認できる。

期待する作用：初代ではターン経過で自然回復する。必要なら回復品・退避・安全な足踏みを比較する。

照合・失敗時：無入力や決定/攻撃の連打を回復操作にしない。隣接敵がいる足踏みや空腹は損失になり得る。回復量は現在の説明・使用後HPから検証する。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### food

適用条件：満腹度が低い、または0。実際の持ち物を確認する。

期待する作用：初代では満腹度0でHPが減る。食料の確定名と食べる選択を確認して利用を検討する。

照合・失敗時：パン等の回復量をリマスターの固定値にしない。未知名の草を食料や安全な回復品と断定しない。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### inventory-equipment

適用条件：現在の道具画面で項目名・カーソル・操作一覧が読める。

期待する作用：武器/盾は装備して効果を得る候補。使用や装備の前後でちから・剣・盾・HP等の観測差を記録する。

照合・失敗時：所持しているだけと装備済みを区別する。呪い・副作用・未識別を確認し、選択中の項目を推測して連続入力しない。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### unidentified

適用条件：仮の名前の品、未識別の杖・指輪等がある。

期待する作用：仮名をその冒険の識別子として持ち、使用・装備・説明・識別の文章と結果を結び付ける。

照合・失敗時：別の冒険の同じ仮名や色だけで本来名を決めない。効果が見えない場合は無効とも安全とも断定しない。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### item-purpose

適用条件：草・巻物・杖等の説明と選択中コマンドが読める。

期待する作用：初代では草は飲む/投げる、巻物は読む、杖は振る等で用途が異なる。説明に合う使い方を選ぶ。

照合・失敗時：同じ品でも使用法や対象で効果が違う。残数・回数・対象方向と新しいメッセージを確認。資料の数値を現在値として捏造しない。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### arrow

適用条件：矢と射線、対象の現在位置を確認できる。

期待する作用：現在キーの矢入力で射撃を候補にできる。敵が遠いだけでは通常攻撃の命中を期待しない。

照合・失敗時：残弾や射線を無視して連射しない。画像の変化だけで命中とせずメッセージと対象の変化を確認する。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### dialogue

適用条件：現在の会話・通常のはい/いいえの選択肢を確認。

期待する作用：会話は決定で進め、通常ははいを選んで決定。現在のカーソルが読めれば配置に合う方向入力を使う。

照合・失敗時：取消はいいえや前画面へ戻る可能性がある。削除・初期化等の保護確認は実行しない。同じ説明へ戻る反復は再検討する。

版・根拠：`user_confirmed` / user-controls

### death-retry

適用条件：死亡・リザルト・やり直し確認が表示された。

期待する作用：結果を進め、通常の再挑戦確認ははいを選ぶ。再挑戦後の階・HP・装備は現在画面から取り直す。

照合・失敗時：取消で店へ戻る可能性がある。前の冒険の地図・敵・レベル・所持品を現在へ引き継がない。

版・根拠：`remaster_general` / steam-remaster-20261025, user-controls

### outside-exit

適用条件：階表示と実マップがなく、白枠のないダンジョン外で操作可能。

期待する作用：利用者の対象環境では固定地形の出口へ移動する。進めない場所がドアなら決定入力で開く可能性を確認する。

照合・失敗時：方向転換だけは出口探索の進展にならない。メニュー・射撃・足踏みを探索候補にしない。会話の枠が出たら地形移動と区別。

版・根拠：`user_confirmed` / user-controls

### goal-return

適用条件：箱や階段・帰還の文章が現在読める。

期待する作用：箱の所持確認後は帰還が必要。初代の目標階や名称は参考にし、現在のダンジョンの説明と利用者の目標を優先する。

照合・失敗時：階への到達・箱を見た・階段を見た、だけでは取得や帰還成功を宣言しない。初代のもっと不思議30階情報で利用者の99階目標を書き換えない。

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

### use-heal

適用条件：次の被ダメージで倒される前に回復する候補。持ち物・説明と現在カーソルで対象品を確認する。

期待する作用：初代資料の参考効果：薬草はHP回復、弟切草はHPと一部状態異常の回復。満タン時の効果は別扱い。

照合・失敗時：使用前後の現在HP/最大HPと状態異常を別々に記録。所持名を過去のHPとして読まない。リマスターの設定・説明・使用後の実測を優先し、資料の効果を確定しない。

1. 道具画面で薬草等を選ぶ
2. 飲む等の自分へ作用するコマンドを確認
3. 決定を1回送りHPと新しい文章を再取得

版・根拠：`sfc_reference` / sfc-wiki-20261025, user-controls

## 斜め攻撃と接近の手番（利用者提供）

通常攻撃は縦横と斜めを含む8方向の隣接マス（相対座標の最大絶対値が1）に届く。斜めの敵でもその方向を向いてNum1で攻撃でき、縦横に並ぶための移動は不要。右上はNum5+W+D、左上はNum5+W+A、右下はNum5+S+D、左下はNum5+S+Aで移動せず向き直す。その後Num1で攻撃し新しい戦闘メッセージを確認する。間に1マス空いた距離2の敵に自分から近づくと、敵は移動をせずその手番に攻撃できる。通常速度で接近する近接敵ならNum6の足踏みで1ターンを渡して敵に隣接まで移動させ、次の自分の手番で先に攻撃する候補を比較する。

接近待ちは無入力ではなくNum6を1回入力する。遠隔・倍速・不動・複数敵・低HP・地形等では成立/安全を仮定せず、回復・退避・遠隔攻撃・道具を比較。1回ごとに現在の敵位置とHPを読み直し、動かない敵に同じ足踏みを繰り返さない。方向転換が成功したことや命中、敵の個体・種別、壁越しの攻撃可否は推測で確定しない。

## 所持品の操作手順と装備効果（利用者提供）

Num0でメニューを開き、道具へカーソルを合わせNum1で決定して所持品一覧を開く。その一覧では左右の操作で所持品の表示を切り替えて内容を確認する。所持上限は20個で、左右入力で上限を増やす意味ではない。使いたいアイテムへカーソルを合わせNum1で決定すると、左側にその品をどう使うか選ぶ選択肢が出る。現在表示された使用方法にカーソルを合わせてNum1で決定する。品を選んだだけでは使用/装備完了ではない。

現在のカーソル・表示中の品・使用方法を各入力後に確認する。見えていないページの品や、まだ見ていない使用方法を作らない。各ページの件数や左右操作後の配置を固定で推測せず、表示内容の変化で確認する。読み終えた表示への循環で確認を反復しない。取消やメニュー終了を使用成功にしない。

装備品は持っているだけでは装備効果がない。所持・カーソル選択・装備コマンド・装備中を区別し、装備中の印と能力値で現在の状態を確認する。装備状態が不明なら所持だけを根拠に剣・盾などの効果を計算しない。

## 足踏みによる回復と回復品の温存（利用者提供）

HP回復には薬草か弟切草を使える。周囲に敵がいない状況では、HP回復目的のために直ちに薬草/弟切草を消費せず、複数回の足踏みによる自然回復を優先して回復品を温存する。現在キーはNum6で足踏みする。無入力の実時間待機はゲーム内の手番を進める足踏みとは異なる。

足踏みは1入力ごとにHP・敵の出現/接近・満腹度を再観測する。満HPならHP回復目的の足踏みを終了する。敵が周囲にいる、空腹、HP低下、回復が観測できない時は薬草/弟切草・退避・他の方法を比較する。自然回復の必要手数や回復量を固定ルールとして捏造しない。満HPで草を使い最大HPを上げる別目的とは区別する。

所持品一覧の操作補足（利用者確認）：上下（W/S）は表示中のアイテム選択、左右（A/D）はページ切替。品名の画面上の横位置の違いからページを切り替えない。ページ切替後は品とカーソルを読み直す。
